# Mallets

Nettleserprogram for slagverk med stemmetoner (xylofon, marimba, vibrafon, klokkespill, rørklokker, pauker m.fl.) – Larvik kulturskole.

## Lenker
- Lærervisning: https://larvikkulturskole.github.io/mallets/
- Elevvisning med låtmeny: https://larvikkulturskole.github.io/mallets/?elev
- Elevvisning, én låt: https://larvikkulturskole.github.io/mallets/?elev&fil=sanger/vinterlandskap.zip

## Innhold
| Mappe/fil | Hva |
|---|---|
| `Mallets.html` | Selve programmet |
| `index.html` | Sender videre til Mallets.html |
| `samples/` | Ekte lydprøver (VCSL, CC0 – se `samples/LISENS.txt`) |
| `sanger/` | Prosjekter (zip) laget med «📦 Lagre alt (zip)» + `liste.json` fra «📋 Lag låtliste» |

Repoet er offentlig: legg ikke ut komp eller bilder uten tillatelse til å publisere dem.
